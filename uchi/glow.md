# glow

- [glow](https://github.com/charmbracelet/glow)
- ターミナルでのマークダウンビューワー
- インストールは `aqua`

## note

- ターミナル上でマークダウンファイルを開いてプレビュー表示
- `glow` と叩くだけでファイル選択が可能
- `glow README.md` のようにファイル名を渡して標準出力して終了させることも可能
- 詳しくはヘルプを参照
- `glow config` で設定ファイルを編集可能
- とくに設定変更しなくても充分使える
