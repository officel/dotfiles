# tfenv

- [tfenv](https://github.com/tfutils/tfenv)
- terraform のバージョンマネージャー
- インストールは `aqua`

## note

- [tfenv が数年ぶりにアップデート](https://zenn.dev/terraform_jp/articles/2026-04-26_terraform_tfenv_v3_2_0)
- [terraform のバージョンマネージャー選び](https://zenn.dev/terraform_jp/articles/2024-08-22_terraform_version_manager)
- `.terraform-version` にバージョン書いておくと自動で切り替わる
- 個人的には beta 等の新バージョンのテストや旧バージョンの使用確認に使っている
- 通常時はだいたい latest

## environment

- 自動インストールを無効にする等の設定ができる
